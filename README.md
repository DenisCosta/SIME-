# SIME³
 O SIME³ é o Sistema Inteligente de Mitigação da Evasão Escolar para Educação de Jovens e Adultos (EJA). Consiste de Inteligência Artificial Preditiva e Analítica (IAPA) ressignificada como uma tecnologia social, dialógica e preventiva. Foi criada para identificação de padrões referentes à Educação do Campo e da EJA.
